# Clubmaster

Clubmaster is a FileMaker Pro project for managing club-related data and operations.

## Overview

The project includes:

- [clubmaster.fmp12](clubmaster.fmp12): the main FileMaker project file
- [img/clubmaster.png](img/clubmaster.png): a screenshot of the interface

## What this project provides

- A FileMaker-based database structure for club management
- A visual reference for the application layout
- Project files that can be opened and customized in FileMaker Pro

## Requirements

To work with this project, you need:

- FileMaker Pro or Claris FileMaker
- A local machine or shared environment for the database

## Getting started

1. Open [clubmaster.fmp12](clubmaster.fmp12) in FileMaker Pro.
2. Review the available layouts and database structure.
3. Customize the project to fit your club’s workflow.

## Project structure

- [clubmaster.fmp12](clubmaster.fmp12): main database project
- [img](img): screenshots and visual references
